# SEVEN DAYS — Cinematic

A found-footage horror game: the Prologue plus seven days, each a recorded tape you can only partly steer. Built for the [RUN.world](https://series-1.gitbook.io/rundot-docs) platform.

**RUN.world is the primary home.** This repository also builds a plain static version (`npm run build:static`, deployed to GitHub Pages by `.github/workflows/pages.yml`): same game, saves in the browser, platform features (cloud saves, clips, leaderboard) off. See [`COMBINED_HANDOFF.md`](COMBINED_HANDOFF.md) for the route and files. The game needs the RUN host only for those platform features.

Play: set `PLAY_URL` in [`docs/index.html`](docs/index.html) once the game has a RUN link.

## Stack

Vite 6 · React 19 · Tailwind v4 · TypeScript · Three.js (`CinemaEngine`: VHS post-pass, procedural Web Audio, Web Speech voice-over) · Pixi 8 · `@series-inc/rundot-game-sdk` 5.28.1

## Visual pipeline

- `src/cinema/vhs.ts`: HDR (half-float) render, quarter-res bloom, a tone curve that stays linear through the shadows, a grade, then the VHS damage.
- `src/cinema/look.ts`: per-chapter exposure/lamp table (`LOOKS`); a procedural surface layer patched onto every standard material (grime, streaks, stains, bump; wood, foliage, metal and ground variants guessed from colour and shape, overridable with `userData.look` / `userData.lookKind`); a shoulder-mounted bodycam lamp with shadows and an albedo-aware auto-iris; dust in the beam; a sky dome.
- `src/cinema/creatureSkin.ts` + `scary.ts`: creatures get smoother geometry, lit wet flesh with veins and a slow writhe, a cold rim light, HDR glowing eyes with pupils, gum-lined teeth, and jointed arms with five curling fingers.
- `src/cinema/humanoid.ts`: procedural people (the friends, Mitzi, the patient).
- `src/cinema/hospitalRoom.ts`: set dressing for both hospital endings.
- `tests/capture/`: a harness that renders any chapter at fixed story times (`shoot.cjs`) or frames every creature (`gallery.cjs`) for before/after comparison.

## Run it

```bash
npm ci
npm run dev          # browser dev; the RUN host isn't present, platform features no-op
npm run typecheck
npm test             # Node tests against a fake RUN host (24 tests)
npm run build        # tsc --noEmit + vite build -> dist/
```

## Deploy to RUN.world

```bash
rundot login
rundot init --name "Seven Days" --description "<one line>" --build-path dist --orientation Portrait   # writes game.config.json
npm run deploy       # build + rundot deploy
```

Before the first deploy:

- Add `public/thumbnail.jpg`, **exactly 512×512 JPG**. It is not in this repo, and `rundot deploy` rejects wrong sizes and placeholders.
- `game.config.json` is generated by `rundot init`; commit it after you run it.
- `rundot/leaderboard.config.json` (Survivors board) and `rundot/liveops.config.json` (banner, ads flag, reminder experiment) define the leaderboard and LiveOps. I haven't verified how the CLI applies them, so check the RUN docs.

## RUN.world API surface in use

All calls live in [`src/sdk/platform.ts`](src/sdk/platform.ts) (plus `store.ts` for saves). Everything is `try/catch`'d and gated on `sdkReady()`, because an unhandled SDK rejection crashes the app.

| Area | Use |
|---|---|
| App storage | Cloud save (`progress-v1`); device save kept, the more advanced one wins on load |
| Device cache | Local save, haptics preference |
| Haptics | Light taps on UI, heavy/medium on scares, success on chapter complete; throttled; player toggle |
| Notifications | Local reminder when the next tape is waiting (delay from LiveOps) |
| Social | Share link with launch intent |
| Clips | Record gameplay and audio, save/share from the HUD |
| Stats + leaderboard | Chapters completed and campaign stats; "Survivors" board with your rank |
| Popups | Toast, like prompt after Day Seven, comments |
| LiveOps + experiments | Menu banner, interstitials flag (off by default), reminder-delay A/B |
| Ads | Interstitial between chapters, only if LiveOps enables it |
| System | Add to home screen |
| Profile | Operator name on the menu |
| Analytics | Funnels per episode, event tracking |
| Lifecycles | Pause/resume/quit persist the save |
| Navigation + shared storage | Hand-off to and from the companion search game (see `TAPE_HANDOFF.md`) |

## Verified vs. not verified

Verified here: `tsc --noEmit` and `vite build` clean; the Node tests (platform layer and save/hydrate logic) pass against a fake host; headless Chromium boots the real build off-host with no errors and no SDK calls, and drives the host-present UI (menu, Survivors, share, clip start/stop, haptics toggles) against a fake host (`npm run test:ui`, needs Playwright).

**Not verified: behaviour on the real RUN host.** The fake host encodes my reading of the docs, not the host's actual behaviour. Specifically untested:

- Clip capture and upload on a real device. The docs say clips don't record in Playground, and the Web Speech voice-over is not captured in clips.
- Haptics feel and local notifications on a device. Local notifications are skipped on web.
- The leaderboard config key shape (`rundot/leaderboard.config.json`). The docs were ambiguous about whether the file needs a wrapping key.
- The cross-game tape link. The code and `TAPE_HANDOFF.md` describe different contracts, and the companion game isn't in this repo.
- Interstitial ads. Gated off by default; the host can throttle them.

## Known gaps

- Binary assets were not exported with the source (see `MISSING_BINARIES.md`): the Aseprite sources, GIF/PNG images and the thumbnail. The asset manifest references `images/placeholder.png`, which is missing: the preload logs one warning and continues, and the game still boots. The thumbnail is required to deploy.
- The source came from a mixed-version snapshot that did not compile. The changes and guesses are listed in [`RECONCILIATION.md`](RECONCILIATION.md); the main guesses are Day Two's creature leg count (4) and no-op `dragStart`/`dragEnd` on the camera rig.
