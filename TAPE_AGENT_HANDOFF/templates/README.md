# SEVEN DAYS — Tape Agent Handoff

Everything the tape agent needs is in this folder.

## Files in this folder

| File | What it is |
| --- | --- |
| `README.md` | This page: start here. |
| `01_TAPE_BRIEF.md` | What a tape is, when each one appears, and the story facts it must respect. |
| `02_PROTOCOL.md` | The exact install steps, file paths, and the messages the game and tape exchange. |
| `03_CHECKLIST_AND_REPLY.md` | Install checklist and the reply to send back to the search side. |
| `04_STORY_SUMMARY.md` | Plain-language story from start to finish, with friends' states and endings. |
| `templates/tape-index.html` | Starter page for a tape (copy into `public/tapes/tapeN/index.html`). |
| `templates/manifest.json` | Manifest format, with the entry shape to add. |
| `reference/TAPE_HANDOFF.md` | Copy of the original cross-game handoff (connection details). |
| `reference/SEVEN_DAYS_MASTER_BIBLE.md` | Copy of the master story bible (story authority). |

## Quick start

1. Read `01_TAPE_BRIEF.md`.
2. Follow `02_PROTOCOL.md` exactly.
3. Build your tape from `templates/tape-index.html`.
4. Fill in `03_CHECKLIST_AND_REPLY.md` and send it back.
